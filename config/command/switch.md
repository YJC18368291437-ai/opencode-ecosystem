---
description: 一键换对话：写最小交接并直接开新会话
---

用户已决定换对话。不要再问是否确认，直接执行：

1. 目标：`$ARGUMENTS`；为空就从当前对话自然延续。
2. 写 ≤10 行交接，只写硬事实：
   - 目标
   - 已完成（带文件/命令/结果）
   - 下一步（最多 3 条）
   - 约束 / 未决
3. 立刻调用 `handoff_session(prompt=<交接>, files=<必要文件>)`：
   - 只带与新会话直接相关的文件，最多 8 个
   - 学习任务：`state.md`、当天 `daily/YYYY-MM-DD.md`、`profile.md`
   - 代码任务：相关源码 / 测试 / 配置
4. 只回复「已开新会话」，不要贴交接全文，不要发送新会话里的内容。
