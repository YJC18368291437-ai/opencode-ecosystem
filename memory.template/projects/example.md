# docs-search（示例项目）

## 当前阶段

**Stage 1 — 先跑通索引，不做 UI。** 已收录 3 篇文档，验收中。

## 目标

用最小的本地脚本，在 Markdown 文档里做关键词检索和结果高亮，证明流程可用。

## 非目标

- 不做向量检索。
- 不做常驻服务。
- 不引入数据库。

## 已完成

- [x] `scripts/index.mjs`：扫描 `docs/`，生成 `index.json`
- [x] `scripts/search.mjs`：按关键词过滤并输出文件行号
- [x] 3 个单元测试

## 已验证

- `node --test` → 3 通过，0 失败
- `node scripts/search.mjs cache` 能返回 2 条带行号的结果

## 未验证 / 风险

- 中文分词没做，只按子串匹配
- 大文件（>1MB）性能未测

## 下一步

1. 加 `--json` 输出，方便后续接 UI
2. 补中文子串测试
3. 用真实文档跑一次端到端
