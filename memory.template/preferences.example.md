# 用户偏好（示例，复制为 preferences.md 后改成你自己的）

- 语言：中文。先给结论，再给必要细节；能接受长解释，但不要空话。
- 水平：会追问原理和数字；解释要具体，避免只给结论。
- 质量优先：可以花小钱在关键处，不接受为了省几分钱产生返工或屎山代码。
- 验证：交付要有证据（命令、通过/失败数、截图）；不接受「做好了」。
- 机器：8GB 内存的笔记本。避免本地模型、向量库、常驻服务。
- 环境：OpenCode 1.19.x + 自定义 provider。
- 成本：月度预算很小；参数必须可调，不要写死。
- 偏好：优先用成熟插件，自己只写薄层；分阶段灰度，每步可回滚。
- 沟通：喜欢先讨论方案、再动手；重要决定要写进长期记忆。
